## [Insight] 데이터의 흐름으로 기록하는 개발자의 일상: 대시보드 업데이트와 회고

안녕하세요, 씨피랩스의 CTO 송주한(Jeffrey)입니다.

엔지니어로서 20년 넘게 커리어를 쌓아오며 제가 가장 중요하게 생각하는 것 중 하나는 '가시성(Visibility)'입니다. 시스템의 상태를 모니터링하는 것뿐만 아니라, 내가 어떤 방향으로 시간을 쓰고 있고 어떤 프로젝트에 에너지를 쏟고 있는지를 데이터로 확인하는 과정은 성장을 위한 필수적인 피드백 루프가 됩니다.

오늘은 제 개인 대시보드의 데이터를 업데이트하며, 최근의 작업 흐름을 정리하는 시간을 가졌습니다. 단순한 `json` 파일 수정처럼 보일 수 있지만, 그 이면에는 개발자로서의 시간 관리와 우선순위에 대한 고민이 담겨 있습니다.

### 📊 데이터가 말해주는 최근의 집중도

오늘 업데이트한 `dashboard.json`의 변경 사항을 보면, 제가 최근 어디에 몰입하고 있었는지 명확히 드러납니다. 특히 `claude-agent` 리포지토리의 활동량이 눈에 띕니다.

```json
"name": "claude-agent",
"last_msg": "docs(log): 10-22 handover snapshot; zabbix patch, PHP survey, consolidation plan",
"activity": [19, 15, 34, 28, 7, 1, 0],
"commits_7d": 116,
"commits_30d": 322
```

최근 30일간 322개의 커밋, 7일간 116개의 커밋이 발생했습니다. 단순한 코드 작성을 넘어 Zabbix 패치, PHP 설문, 통합 계획(consolidation plan) 등 인프라와 아키텍처를 아우르는 복합적인 작업들이 진행되었음을 알 수 있습니다. AI 에이전트를 활용한 자동화와 효율화 작업은 제가 최근 가장 깊게 파고 있는 기술적 도전 중 하나입니다.

### 🛠️ 기술적 결정: 정적 데이터 기반의 가벼운 대시보드

많은 분이 실시간 대시보드를 위해 무거운 DB와 API 서버를 구축하곤 합니다. 하지만 저는 개인적인 기록 용도로는 `JSON` 파일을 통한 정적 데이터 관리 방식을 택했습니다. 

그 이유는 간단합니다. **"오버엔지니어링을 경계하기 위해서"**입니다. 
- **낮은 유지보수 비용:** 서버리스 환경(GitHub Pages)에서 추가 비용 없이 운영 가능합니다.
- **버전 관리:** 데이터의 변경 이력이 Git 커밋 로그에 그대로 남기 때문에, 특정 시점의 내 활동량을 추적하기 매우 용이합니다.
- **빠른 응답 속도:** 클라이언트 사이드에서 JSON을 파싱하여 렌더링하므로 지연 시간이 거의 없습니다.

### 💡 이번 업데이트를 통해 느낀 점

데이터를 갱신하며 `heritageradio`나 `booksummary` 같은 프로젝트의 활동 수치가 낮아진 것을 보았습니다. 이는 단순히 '방치'한 것이 아니라, `claude-agent`라는 더 큰 우선순위에 집중하기 위해 의도적으로 리소스를 배분한 결과입니다.

전문가로서 가장 위험한 상태는 '모든 것을 조금씩 다 하는 것'입니다. 때로는 특정 프로젝트에 폭발적인 에너지를 쏟아붓고(Deep Work), 그 성과를 바탕으로 다른 프로젝트에 전이시키는 전략이 필요합니다. 이번 대시보드 업데이트는 제가 계획한 대로 '선택과 집중'을 잘 수행하고 있는지 확인하는 일종의 '셀프 체크포인트'였습니다.

### 마치며

코드 한 줄, JSON 값 하나를 바꾸는 작업이라도 그 안에 나만의 철학과 인사이트를 담는다면 그것은 단순한 작업(chore)이 아니라 성장의 기록이 됩니다. 씨피랩스에서도 이러한 데이터 기반의 사고와 효율적인 리소스 배분을 통해 팀과 서비스가 함께 성장할 수 있도록 끊임없이 고민하겠습니다.

여러분은 자신의 성장 궤적을 어떻게 기록하고 계신가요?
