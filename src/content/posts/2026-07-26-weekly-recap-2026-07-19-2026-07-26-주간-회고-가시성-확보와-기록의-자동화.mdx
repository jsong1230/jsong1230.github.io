# [Weekly Retrospective] 가시성(Visibility)의 확보와 기록의 자동화: 데이터로 증명하는 성장

안녕하세요, 씨피랩스(CP Labs)의 CTO 송주한(Jeffrey)입니다.

2026년 7월 셋째 주와 넷째 주에 걸친 한 주를 마무리하며, 지난 7일간의 개발 여정을 되짚어 봅니다. 이번 주는 화려한 아키텍처의 설계보다는 **'가시성(Visibility)의 확보'**와 **'데이터 정합성 검증'**이라는, 엔지니어링의 가장 기본적이면서도 본질적인 가치에 집중한 시간이었습니다.

### 🛠️ 이번 주의 주요 작업: 기록의 시스템화

이번 주 저의 작업 흐름은 크게 두 가지 축으로 나뉘었습니다.

**첫째, 개인 개발 대시보드의 고도화와 데이터 동기화입니다.** 
매일 `dashboard.json`을 업데이트하며 제가 관리하는 여러 리포지토리(`heritageradio`, `metadium_homepage`, `claude-agent` 등)의 활동 지표를 추적했습니다. 단순히 숫자를 갱신하는 `chore` 작업처럼 보일 수 있지만, 이는 저에게 일종의 '자기 객관화' 과정입니다. 어떤 프로젝트에 에너지를 쏟고 있는지, 기술적 관심사가 어떻게 전이되고 있는지를 데이터로 확인하며 생산성 피드백 루프를 구축하는 작업이었습니다.

**둘째, '헤리티지 라디오' 프로젝트의 데이터 정합성 검증 도구 구축입니다.** 
대량의 오디오 콘텐츠를 생성할 때 발생할 수 있는 '논리적 결함'을 잡기 위해 `verify_news_era.py`를 신설했습니다. `ffprobe`와 `volumedetect`를 활용해 실제 재생 시간과 라우드니스를 체크하는 로직을 구현하며, "로그에 에러가 없으니 성공했다"는 믿음보다 "실제 데이터가 기준에 부합하는가"를 검증하는 방어적 엔지니어링의 중요성을 다시금 체감했습니다.

### 💡 기술적 인사이트: '믿음'이 아닌 '검증'의 가치

이번 주 작업을 통해 얻은 가장 큰 인사이트는 **'신뢰할 수 있는 시스템은 철저한 검증 도구 위에서 만들어진다'**는 점입니다. 

원격 작업 중 `SIGHUP` 발생으로 프로세스가 종료되었던 장애 사례를 `CHANGELOG.md`에 포스트모템(Post-mortem) 형태로 기록하며, 실패를 자산화하는 습관의 중요성을 느꼈습니다. 또한, JSON 기반의 정적 데이터 관리 방식이 주는 효율성과 동시에, 데이터가 비대해짐에 따라 발생하는 Git diff의 가독성 저하 문제를 발견했습니다. 이를 통해 향후 데이터 구조를 레포지토리별로 분리하거나, 정렬 로직을 강제하는 CI/CD 파이프라인(GitHub Actions) 도입의 필요성을 절감했습니다.

### 📖 생각의 확장: 기록의 기술과 기억의 예술

기술적인 몰입 사이에서 한강 작가의 소설 『흰』을 읽으며 잠시 호흡을 가다듬었습니다. 모든 것을 데이터화하고 불변의 기록으로 남기려는 Web3/DID의 지향점과 달리, 소설이 말하는 '지워짐'과 '공백'의 가치는 저에게 신선한 충격을 주었습니다. 

엔지니어로서 '완벽한 기록'을 추구하지만, 때로는 그 기록되지 않은 여백과 상실의 흔적이 인간의 본질을 더 잘 드러낸다는 역설을 배웠습니다. 이는 제가 추구하는 '데이터 기반의 성장'이 자칫 숫자의 함정에 빠지지 않도록 경계하게 만드는 소중한 성찰의 시간이었습니다.

### 🚀 다음 주를 향한 생각

다음 주에는 이번 주에 도출된 개선 사항들을 실제 액션 아이템으로 옮기려 합니다.

1. **대시보드 업데이트 자동화**: 수동 커밋을 최소화하기 위해 GitHub Actions를 이용한 데이터 수집 및 자동 푸시 파이프라인을 구축하겠습니다.
2. **데이터 구조 최적화**: 비대해진 `dashboard.json`을 모듈화하여 관리 효율성과 Diff 가독성을 높이겠습니다.
3. **검증 로직 확장**: 오디오 검증 도구를 넘어, 생성된 콘텐츠의 메타데이터와 실제 파일 간의 정합성을 전수 조사하는 자동화 스크립트를 고도화하겠습니다.

데이터의 흐름을 읽는 눈과 인간의 마음을 읽는 결을 동시에 갖춘 엔지니어로 성장해 나가겠습니다.

**Jeffrey Joo-Han Song**
*CTO, CP Labs*
